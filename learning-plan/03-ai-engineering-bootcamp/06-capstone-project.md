# Lesson 06: Capstone Project + Portfolio

**Estimated time:** 15-20 hours
**Week(s):** 6+

## Goal

Take the project you started in Lesson 05 and harden it into a portfolio-grade showcase. This is what you'll show in interviews.

---

## Capstone Requirements

### Technical
- [ ] **All 5 lesson topics represented:**
  - Prompt engineering (sophisticated prompts, not basic ones)
  - RAG with optimizations (chunking strategy, reranking, or hybrid search)
  - At least one agent / tool use pattern
  - MLOps: tracked experiments, evaluation suite, monitoring
  - Guardrails: input validation, output filtering, cost controls
- [ ] **MCP integration** — Either expose your app as MCP server, or consume MCP tools in it
- [ ] **End-to-end deployment** — Runs at a public URL
- [ ] **Quantitative evaluation** — Numbers showing it works (accuracy, latency, cost)

### Documentation
- [ ] **README** with architecture, setup, examples
- [ ] **Architecture diagram** (data flow, components)
- [ ] **API documentation** (if applicable)
- [ ] **Cost analysis** (per query, projected at scale)
- [ ] **Eval report** (golden dataset results)
- [ ] **Failure mode analysis** (what breaks, how it's handled)

### Portfolio
- [ ] **Blog post** (Medium, Substack, dev.to, or personal site)
- [ ] **Demo video** (Loom or YouTube, 5-10 min)
- [ ] **LinkedIn post** with the build journey
- [ ] **GitHub repo** polished and pinned

---

## Interview Prep — AI Engineering

### Key Topic Areas

#### 1. LLM Fundamentals
- [ ] How do transformers work (high level)?
- [ ] What is fine-tuning vs. RAG vs. prompting? When to use each?
- [ ] What are tokens? How does pricing work?
- [ ] What is temperature, top-p, top-k?

#### 2. RAG
- [ ] How does basic RAG work?
- [ ] What chunking strategy and why?
- [ ] How do you evaluate a RAG system?
- [ ] When does RAG fail and how do you fix it?

#### 3. Agents
- [ ] What is an agent vs. just LLM + tools?
- [ ] When do you need multi-agent vs. single-agent?
- [ ] How do you prevent agent loops / runaway costs?
- [ ] What is MCP and why does it matter?

#### 4. Production Systems
- [ ] How do you monitor an LLM app?
- [ ] How do you handle prompt injection?
- [ ] How do you A/B test prompts?
- [ ] What's your cost model?

#### 5. Trade-offs
- [ ] OpenAI vs. Claude vs. open source
- [ ] LangChain vs. raw API
- [ ] Vector DB selection
- [ ] When NOT to use AI
